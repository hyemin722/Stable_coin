Blockchain Practice Final Project

Upbit MCP 실시간 코인 정보 대시보드

MCP 클라이언트가 MCP 서버의 tool을 호출하여 Upbit의 실시간 코인 가격, 24시간 변동률, 거래량, 거래대금, 호가창/주문장, 최근 체결 내역, 주요 코인 비교 데이터를 조회하는 프로젝트입니다.

Browser UI
Web Backend
MCP ClientSession
Upbit MCP Server
Upbit Public API

조회 설정

MCP Tool Discovery

get_market_list
업비트에서 거래 가능한 마켓 목록을 조회합니다.
get_ticker
선택한 마켓의 현재가, 24시간 변동률, 거래량, 거래대금을 조회합니다.
get_orderbook
선택한 마켓의 호가창/주문장 데이터를 조회합니다.
get_recent_trades
최근 체결 내역을 조회합니다.
get_market_summary
현재가, 최우선 매수·매도 호가, 스프레드, 거래대금을 요약합니다.
compare_markets
주요 코인의 현재가, 변동률, 거래대금을 비교합니다.
get_minute_candles
분봉 캔들 데이터를 조회합니다.

실행 결과

대기 중
MCP 서버에서 반환된 Upbit 실시간 데이터 조회 결과가 이 영역에 표시됩니다.
